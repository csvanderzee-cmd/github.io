How to Play

Joining, hosting and running a weekly match.

OverviewRulesHow to PlayScheduleStandingsLive Events

Joining a match (players)

  1. Open Minecraft Education and choose Join World. Enter the four-picture join code the host gives you.
  2. Follow your team's coloured path, red or blue, to the team manager.
  3. "Talk" to the team manager and choose Join as Player. Wait for the host to start the match.

Hosting a match

  • Use a reliable computer, plugged in, that nobody plays on during the match.
  • Import the league's world file (.mcworld). How schools get it: To be decided
  • Start hosting and share the join code with both teams.
  • Set the team size to 5 (/function 5team) before starting. Leave the match at its full 20 minutes.
  • At zero: screenshot the Score and Frags boards (see Rules 4).

Host commands

Commands the host types in chat
CommandWhat it does
/function startStarts the match
/function pausePauses the match
/function resumeContinues after a pause
/tag @s add spectatorHost switches to spectator mode
/tag @s remove spectatorLeaves spectator mode
/function 3team … /function 10teamTeam size, 3 to 10 a side. League matches use 5team, before the match starts
/function 15min, 10min…Shortens the match. League matches use the full 20 minutes, so these are not needed

Match day, step by step

  1. To be decided before: host opens the world, sets 5v5, shares the join code.
  2. Players join and pick their team at the team manager.
  3. Both coaches confirm rosters and settings in chat.
  4. Host starts the match with /function start.
  5. At zero: host screenshots both scoreboards; coaches confirm.
  6. Result entered in the league sheet the same day.

Schools outside the district

Minecraft Education join codes normally only work inside one school organization. For a team from another district to join a PSD-hosted world (or the other way round), both organizations' IT administrators may need to enable cross-organization play first. Ask your IT team early; matches can't be scheduled until it works.
